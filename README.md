# Annona — Помощник заказов

**Cura Abundantiae** — Система анализа и оптимизации заказов

## 📁 Структура проекта

Проект был рефакторирован из единого HTML-файла в модульную архитектуру по лучшим мировым практикам:

```
/workspace
├── index.html          # Главный HTML-файл (точка входа)
├── styles/
│   └── main.css        # Все стили приложения
├── js/
│   ├── main.js         # Точка входа JavaScript, инициализация
│   ├── state.js        # Управление состоянием приложения
│   ├── utils.js        # Вспомогательные утилиты
│   ├── analyzer.js     # Бизнес-логика анализа данных
│   ├── fileHandler.js  # Обработка файлов (загрузка, парсинг Excel)
│   └── ui.js           # Отрисовка интерфейса (таблицы, графики, KPI)
└── Annona.html         # Оригинальный файл (сохранён для истории)
```

## 🏛️ Архитектура

### Модули JavaScript (ES Modules)

1. **main.js** — Точка входа
   - Инициализация приложения
   - Подключение обработчиков

2. **state.js** — State Management
   - Централизованное хранилище данных
   - Геттеры/сеттеры для доступа к состоянию
   - Управление настройками

3. **utils.js** — Утилиты
   - DOM helper (`$`)
   - Форматирование чисел и валют
   - Экранирование HTML
   - Toast уведомления

4. **analyzer.js** — Бизнес-логика
   - Анализ товаров
   - Расчёт рекомендаций заказа
   - Классификация по статусам
   - Обработка аномалий продаж

5. **fileHandler.js** — Работа с файлами
   - Drag & Drop загрузка
   - Парсинг Excel (XLSX)
   - Извлечение мета-данных

6. **ui.js** — Пользовательский интерфейс
   - Отрисовка таблиц
   - Графики Chart.js
   - KPI показатели
   - Обработчики событий

### Стили

- **styles/main.css** — Вынесенные CSS-стили
  - CSS переменные для темизации
  - Компонентные классы
  - Анимации и переходы

## 🚀 Запуск

Для работы приложения необходим локальный HTTP-сервер (из-за использования ES Modules):

```bash
# Вариант 1: Python
python -m http.server 8000

# Вариант 2: Node.js (npx)
npx serve .

# Вариант 3: PHP
php -S localhost:8000
```

Затем откройте в браузере: `http://localhost:8000/index.html`

## 📊 Функционал

- **Загрузка Excel** — Drag & Drop или выбор файла
- **Анализ остатков** — Глубокий анализ продаж и запасов
- **Умный заказ** — Рекомендации на основе алгоритмов
- **KPI панель** — 6 ключевых показателей
- **Графики** — Статусы, сравнение, распределение запаса
- **Фильтры** — Вкладки по статусам товаров
- **Настройки** — Гибкая конфигурация параметров
- **Экспорт** — Выгрузка рекомендаций в Excel

## 🎨 Дизайн-система

Цветовая палитра в CSS переменных:
- `--gold` / `--gold-soft` — Золотые акценты
- `--aegean` — Синий (Эгейское море)
- `--terracotta` — Терракотовый
- `--ochre` — Охра
- `--olive` — Оливковый
- `--crimson` — Красный
- `--marble` / `--ivory` — Светлые фоны
- `--ink` / `--ink-soft` — Текст

Шрифты:
- **Cinzel** — Заголовки (font-display)
- **Cormorant Garamond** — Основной текст
