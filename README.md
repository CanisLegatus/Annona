# ANNONA — Помощник заказов

**Cura Abundantiae** — Система умного анализа товарных запасов

## 🏛️ Архитектура проекта

Проект разделён на модули по принципу **Separation of Concerns**:

```
/workspace
├── index.html          # Точка входа (HTML-разметка)
├── styles/
│   └── main.css        # Все стили приложения
├── js/
│   ├── main.js         # Главный файл инициализации
│   ├── state.js        # Управление состоянием (State Management)
│   ├── utils.js        # Вспомогательные утилиты
│   ├── analyzer.js     # Бизнес-логика анализа данных
│   ├── fileHandler.js  # Обработка файлов (Excel)
│   └── ui.js           # Отрисовка интерфейса
├── Annona.html         # Оригинальный файл (для отката)
└── README.md           # Этот файл
```

## 📦 Модули

### `index.html`
- Чистая HTML-разметка без встроенных стилей и скриптов
- Подключение внешних библиотек через CDN:
  - TailwindCSS
  - SheetJS (xlsx)
  - Chart.js
  - Fontsource (шрифты Cinzel, Cormorant Garamond)

### `styles/main.css`
- CSS-переменные для темизации
- Стили компонентов: glassmorphism, кнопки, карточки KPI, таблицы
- Анимации и переходы

### `js/main.js`
- Точка входа приложения
- Инициализация обработчиков файлов и UI
- Запуск после загрузки DOM

### `js/state.js`
- Централизованное хранилище состояния
- Геттеры/сеттеры для данных
- Настройки приложения (targetDays, excludedCubes и др.)

### `js/utils.js`
- Утилиты для работы с DOM (`$`)
- Форматирование чисел и валют
- Проверка файлов, toast-уведомления

### `js/analyzer.js`
- **Бизнес-логика** анализа товаров
- Классификация по статусам (critical, understock, overstock, anomalies, promo, normal)
- Расчёт умного заказа с учётом МТЗ, мин. партии, аномалий продаж

### `js/fileHandler.js`
- Drag & Drop загрузка файлов
- Парсинг Excel через SheetJS
- Извлечение мета-данных (магазин, номер заказа)
- Построение карты колонок

### `js/ui.js`
- Отрисовка KPI, графиков (Chart.js), таблиц
- Переключение вкладок, поиск
- Экспорт в Excel
- Панель настроек

## 🚀 Запуск локально

### Вариант 1: Python HTTP Server (рекомендуется для ES Modules)

```bash
# На порту 8081
python3 -m http.server 8081

# Или с поддержкой CORS для модулей
python3 test-server.py
```

Откройте в браузере: **http://localhost:8081**

### Вариант 2: Live Server (VS Code)
Установите расширение **Live Server** и нажмите "Go Live"

### Вариант 3: Node.js http-server
```bash
npx http-server -p 8081 --cors
```

## ⚙️ Требования к браузеру

- Chrome 61+, Firefox 60+, Safari 11+, Edge 79+

## 📊 Формат входного файла

Excel (.xlsx) со следующими колонками:
- Код, Группа/Товар, Категория куб
- Остаток факт, Продажи всего, История продаж (-1..-4 недели)
- Заказ итого, Рек, Себестоимость, МТЗ, Мин. партия
- Товар в пути, Товар в поставке, Акции

## 🔧 Настройки системы

- **Целевой запас**: 24–30 дней
- **Критический пересток**: 60 дней
- **Дней до поставки**: 6 (пятница → четверг)
- **Порог аномалии**: 2× от среднего
- **Порог неликвида**: ≤2 шт за 4 недели
- **Исключённые кубы**: !ВНЕ_АМ-1, ЗО, ЗО вр, ЗО сеть
